# Calculadora de IMC com Firebase

## Como rodar

1. Instale as dependências:

   ```bash
   npm install
   ```

2. Coloque suas próprias chaves em `src/firebaseConfig.js`.

3. Inicie o app:

   ```bash
   npx expo start
   ```

   Aperte `w` para abrir no navegador, ou leia o QR code com o app Expo Go no celular.
